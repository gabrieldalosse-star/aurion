AURION — WEB APP FINANCEIRO

PARA USAR AGORA
1. Extraia este ZIP.
2. Abra Aurion.html no Chrome, Edge ou Safari atualizado.
3. Explore os exemplos fictícios.
4. Em menu > Começar de novo, selecione Começar com dados vazios.
5. Configure a data inicial e os saldos das contas em menu.
6. Use adicionar para lançar entradas, saídas, diários, economias e cartões.

SALDOS E HORIZONTE
A grade mostra os meses lado a lado. Role para baixo para ver todos os dias e para o lado para mudar de mês. Clique no dia para abrir os detalhes ou em uma célula para cadastrar uma movimentação.
O saldo é projetado: inclui lançamentos previstos. Verde indica acima da margem de segurança, amarelo abaixo da margem e vermelho saldo negativo.
Em totais estão performance, economizado, custo de vida e diário médio.

SEUS DADOS
Os dados ficam no navegador e neste dispositivo. Salve um backup JSON regularmente em menu. Não há sincronização entre dispositivos, login próprio nem integração bancária automática. A previsão diária é adicional aos valores lançados; evite contar a mesma despesa duas vezes. Metas acompanham valores separadamente, enquanto lançamentos do tipo economia reduzem o caixa projetado.

PUBLICAÇÃO
A pasta fonte/dist está pronta para hospedagem estática. Publique todo o conteúdo dessa pasta em GitHub Pages, Firebase Hosting ou outro servidor. Se publicar, o endereço terá armazenamento separado do arquivo local: exporte o backup e restaure no novo endereço. O modo local não tem autenticação própria; escolha o acesso adequado na hospedagem.

VALIDAÇÃO
Cálculos verificados: centavos, parcelas, recorrências, meses curtos, fechamento e vencimento de cartão, confirmação de lançamento, previsão e simulação. No navegador foi testado cadastrar, recarregar e remover o lançamento criado para teste.
A interface foi reconstruída a partir de telas visíveis na demonstração pública https://www.youtube.com/watch?v=2wBRoff0E9A . Equivalência integral com todas as funções e regras internas do App do Breno não foi verificada.
